# 📚 Libraries

- **AndroidX**
  - core-ktx, appcompat, activity, constraintlayout, lifecycle-viewmodel-ktx, lifecycle-livedata-ktx, fragment-ktx, recyclerview 등: 안드로이드의 필수 컴포넌트 및 최신 아키텍처 지원
- **Jetpack Compose**
  - compose-bom, ui, ui-graphics, ui-tooling, ui-tooling-preview, material3: 최신 선언형 UI 개발
- **Material Components**
  - com.google.android.material:material: 구글 머터리얼 디자인 UI 컴포넌트
- **Navigation**
  - androidx.navigation:navigation-fragment-ktx, navigation-ui-ktx: 네비게이션(화면 이동) 컴포넌트
- **Glide**
  - com.github.bumptech.glide:glide, glide-compiler: 이미지 로딩 및 캐싱
- **Retrofit**
  - com.squareup.retrofit2:retrofit, converter-gson: REST API 통신 및 JSON 파싱
- **OkHttp**
  - okhttp3:okhttp, logging-interceptor: HTTP 네트워킹 및 로깅
- **Gson**
  - com.google.code.gson:gson: JSON 파싱
- **Flexbox**
  - com.google.android.flexbox:flexbox: 유연한 레이아웃 구현
- **Kakao SDK**
  - com.kakao.sdk:v2-user: 카카오 로그인 및 API 연동
- **Naver SDK**
  - com.navercorp.nid:oauth: 네이버 로그인 및 인증
- **SwipeRevealLayout**
  - com.github.chthai64:SwipeRevealLayout: 스와이프 레이아웃 구현
- **Firebase**
  - com.google.firebase:firebase-messaging: 푸시 알림 등 파이어베이스 기능
